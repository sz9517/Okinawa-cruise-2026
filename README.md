# 🚢 Okinawa Cruise Trip Planner 2026

A mobile-friendly trip planner for a 4-day cruise departing from Keelung, stopping at **Naha (Okinawa)** and **Ishigaki Island** in November 2026.

## ✨ Features

- 📋 Shopping lists for Naha & Ishigaki — organized by store and category
- ✅ Check off items as you buy them, with actual price input
- 💴 Real-time JPY → TWD conversion (based on 3-month average rate)
- 💰 Running total by port + grand total at the bottom
- ✏️ Add custom items and wish lists per island
- 🍽️ Restaurant options for each port
- 🗺️ Itinerary with walking times and optional spots
- 🛃 Taiwan customs rules, Japan tax refund info (new 2026 Refund system)
- 🆘 Tsunami & earthquake evacuation locations with Google Maps links
- 💾 All data saved locally in your browser — works offline, multi-user safe

## 🗂️ Pages

| Tab | Contents |
|-----|----------|
| 🌺 Naha | Itinerary, shopping lists, restaurant options, disaster prep items |
| 🪸 Ishigaki | Itinerary, local-only products, supermarket finds |
| 🚢 Ship | On-board shopping (duty-free, souvenirs) |
| 📋 Notes | Customs rules, tax refund, payment tips, evacuation info |

## 👥 Multi-user

Each person opens the same URL in their own browser. All check-offs, custom items, and amounts are stored locally and never shared — everyone gets their own independent copy.

## 🚀 Usage

Open the GitHub Pages link and start checking off items as you shop.  
No installation, no login, no internet required after first load.
