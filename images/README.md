# 商品圖片

這個資料夾放購物清單的商品照片。照片的**檔名 = 品項編號**，網頁會自動對應，不用改 index.html。

## 查詢品項編號

在網址最後加上 `?photo` 打開「照片模式」：

```
https://sz9517.github.io/Okinawa-cruise-2026/?photo
```

每個品項右側會出現一個虛線框，裡面寫著它的編號（例如 `nc3`），點一下就會複製。
最上方會顯示目前有幾個品項已經有照片。

## 上傳照片（GitHub 網頁版）

1. 照片改名成「編號.jpg」，例如 `nc3.jpg`（`.png`、`.webp` 也可以）
2. 打開 repo 的 `images` 資料夾 → 右上角 **Add file → Upload files**
3. 把照片拖進去（一次可以拖很多張）→ 按 **Commit changes**
4. 等 1～3 分鐘 GitHub Pages 部署完成，重新整理網頁就會看到

手機上 GitHub App 不能上傳檔案，請用手機瀏覽器開 github.com，並切換成「電腦版網站」。

## 修改清單時的規則

- **已經有的品項，不要改它的編號**，照片才不會對錯。品名、價格、說明可以隨便改
- **刪除品項沒關係**，其他品項的編號不會變
- **新增品項時，給一個沒用過的新編號**，例如同一類最後一個是 `nc78`，新的就用 `nc79`
- 刪掉的品項編號不要再拿來給新品項用，不然會套到舊照片
- 如果編號不小心重複，照片模式最上方會出現紅色警告

## 其他

- 也可以在品項資料裡用 `img:'images/任意檔名.jpg'` 指定照片，指定的會優先使用（例如首里石鹼用的是 `suisavon.jpg`）
- 建議照片寬度 600～1080px、檔案 300KB 以下，船上網路慢時比較快
- 網頁會記住上次讀到的照片清單，船上沒網路時也知道哪些品項有照片（照片本身則要靠瀏覽器暫存，出發前先在手機上把有照片的分類都打開看過一次比較保險）
