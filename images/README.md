# 商品圖片

這個資料夾放購物清單的商品照片。

- **格式固定為 WebP**（`.webp`），其他格式網頁不會讀取
- **檔名 = 品項編號**，例如 `nc3.webp`，網頁會自動對應，不用改 index.html

## 新增照片

1. 用電腦版 Chrome 或 Edge 打開照片模式（網址最後加 `?photo`）：
   https://sz9517.github.io/Okinawa-cruise-2026/?photo
2. 展開分類，點品項右側的虛線框，選一張照片
3. 網頁會自動把照片縮成最長邊 1000px、轉成 WebP，並下載成正確檔名（例如 `nc3.webp`）
4. 到 repo 的 `images` 資料夾 → **Add file → Upload files** → 拖進下載的檔案 → **Commit changes**
5. 等 1～3 分鐘 GitHub Pages 部署完成，重新整理網頁就會看到

手機上的 Safari 可能無法轉成 WebP，會跳出提示，請改用電腦操作。
GitHub App 不能上傳檔案，用手機上傳請開瀏覽器並切換成「電腦版網站」。

## 換照片／刪照片

- **換照片**：用同一個檔名再上傳一次就會覆蓋（照片模式只對還沒有照片的品項顯示虛線框，換照片時可以先刪掉舊檔，或用其他工具轉檔）
- **刪照片**：在 images 資料夾點那個檔案 → 右上角「⋯」→ Delete file → Commit

## 修改清單時的規則

- **已經有的品項，不要改它的編號**，照片才不會對錯。品名、價格、說明可以隨便改
- **刪除品項沒關係**，其他品項的編號不會變
- **新增品項時，給一個沒用過的新編號**，例如同一類最後一個是 `nc78`，新的就用 `nc79`
- 刪掉的品項編號不要再拿來給新品項用，不然會套到舊照片
- 如果編號不小心重複，照片模式最上方會出現紅色警告

## 其他

- 網頁會記住上次讀到的照片清單，船上沒網路時也知道哪些品項有照片（照片本身則要靠瀏覽器暫存，出發前先在手機上把有照片的分類都打開看過一次比較保險）
